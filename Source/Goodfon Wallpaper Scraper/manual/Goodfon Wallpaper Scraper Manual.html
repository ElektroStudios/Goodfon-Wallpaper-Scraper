01 · Overview

What is GoodFon Wallpaper Scraper?

GoodFon Wallpaper Scraper is a Windows desktop application that automates the mass-harvesting of original-resolution wallpapers from Goodfon.com.

It is a fully automated, rule-based media downloader. By combining user-defined keyword filtering with automated session and IP management, the program handles catalog discovery and asset extraction completely on autopilot. It uses up to 24 concurrent threads per page, smartly rotates your Goodfon accounts to bypass NSFW restrictions, and integrates with Proton VPN to avoid server-side daily download limits.

⚠️ Goodfon enforces a strict hard limit of 80 daily downloads per guest IP. To run this scraper indefinitely and download tens of thousands of images, Proton VPN must be installed and running.
02 · How It Works

Processing Pipeline

Understanding the internal flow helps you configure the tool correctly:

input Search Terms
→
http query Goodfon.com
→
filter Forbidden Keywords
→
if 403 restricted Auth / Rotate VPN
→
output Original Wallpaper

The tool processes pages sequentially but downloads 24 wallpapers at once. If it detects a forbidden keyword in the image URL, it drops it. If an image requires an account (mature content), it automatically injects a session from Accounts.json. If the IP hits the daily limit, it automatically triggers a Proton VPN server switch.

03 · Quick Start

Getting Up & Running

01
Locate the configuration files
Inside the Config folder next to the executable, you will find Search Terms.txt, Forbidden Keywords.txt, and Accounts.json.
02
Fill in your search terms
Edit Search Terms.txt. Add one query per line. The scraper automatically processes these terms as search queries, user profiles, and tag indices.
03
Define what to exclude (optional)
Edit Forbidden Keywords.txt. Any wallpaper URL containing these words will be skipped. Good for filtering out things like watermarks or specific unwanted tags.
04
Add Goodfon accounts (optional but recommended)
Edit Accounts.json to include registered Goodfon accounts. These are strictly used when the scraper hits a 403 Forbidden barrier (mature/restricted content).
05
Connect your VPN
Ensure the Proton VPN client for Windows is running and connected. A paid plan is heavily recommended to avoid severe cooldown penalties during automatic server rotations.
06
Run the application
Double-click the executable. The app will navigate Goodfon, track downloaded URLs via MD5 hashes (to avoid duplicates in future sessions), and save full-res images to the Output folder.

07 · FAQ

Frequently Asked Questions

Can I use the free version of Proton VPN? ▼
While the program can technically interface with the free tier of the Proton VPN client for Windows, doing so is highly unstable. The free version imposes severe multi-minute cooldown penalties for server switching, which forces the scraper to halt or time out. For an uninterrupted automated experience, a paid Proton VPN plan is heavily recommended.
Why am I getting empty results or 0 pages found? ▼
This usually means your search term doesn't exist on Goodfon, or the site is temporarily blocking your current IP before the scraper can even initiate a VPN rotation. Check your terms or try connecting to a different VPN server manually before starting.
01 · Introducción

¿Qué es GoodFon Wallpaper Scraper?

GoodFon Wallpaper Scraper es una aplicación de escritorio para Windows diseñada para la recolección masiva y automatizada de wallpapers en resolución original desde Goodfon.com.

Se trata de un descargador completamente automatizado basado en reglas. Combinando el filtrado por palabras clave con la gestión automática de sesiones y cambios de IP, el programa descubre los catálogos y extrae el contenido en piloto automático. Utiliza hasta 24 hilos concurrentes por página, rota de manera inteligente tus cuentas de Goodfon para saltar restricciones NSFW y se integra con Proton VPN para evadir los límites diarios de descargas.

⚠️ Goodfon impone un límite estricto de 80 descargas diarias por IP invitada. Para que el scraper funcione ininterrumpidamente y descargue decenas de miles de imágenes, es necesario tener instalado y ejecutándose Proton VPN.

07 · Preguntas Frecuentes

FAQ

¿Puedo utilizar la versión gratuita de Proton VPN? ▼
Aunque puedes utilizar la versión gratuita del cliente Proton VPN para Windows, los resultados pueden ser inestables debido a limitaciones implícitas de la versión gratuita, que además impone tiempos prolongados de espera de varios minutos para permitir el cambio del servidor actual. La opción más recomendable es utilizar un plan de pago para poder descargar decenas de miles de wallpapers en cuestión de horas.
¿Por qué mis búsquedas devuelven cero resultados o páginas vacías? ▼
Normalmente significa que el término no existe en Goodfon, o bien que el servidor de Goodfon ha bloqueado temporalmente tu IP invitada antes siquiera de que el scraper pudiese iniciar el protocolo de rotación. Prueba con otros términos o cambia manualmente el servidor VPN antes de iniciar.
